# Morni Angelkönig

Der Angel-Modus des Minecraft-Netzwerks **MoinMorni** (moinmorni.net): **Gemütlich angeln im Alpen-Tal** – eigene
Fische der Alpen, vier Fangplätze, Fischhändler, Fischbuch, Aufgaben des Tages und alle 15 Minuten ein Angel-Turnier.
Ein Paper-Plugin für Paper 26.x (Java 25). Es läuft im Netzwerk und auch ganz allein.

Englischer Name: **Angler King**.
